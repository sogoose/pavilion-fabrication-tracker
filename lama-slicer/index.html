Browser geometry edition. This calculates real planar contours and two standard infill styles, but does not reproduce the original Python N1/N2 weave algorithms. Generated robot-neutral G-code is for verification and further post-processing, not direct robot execution. Comau PDL is not supported in this edition.
No mesh is uploaded to a server. The slicer runs in a separate worker, keeping the Tracker unaffected.
