# The Translation — slide assets

The Chapter 03 presentation viewer in `hello-earth/index.html` expects nine original-layout slide images in this directory:

`slide-01.avif` through `slide-09.avif`.

Images are 2048 × 1447 pixels, preserving all original slide content.
Download the prepared slide package, extract it, and use GitHub's **Add file → Upload files** to place the nine `.avif` images alongside this README.

The interface has previous/next controls, an image filmstrip, an active slide counter, arrow-key navigation and a full-resolution viewer.
